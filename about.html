Course Overview

Understanding the Core Concepts

This project is part of Cloud Computing Practical Lab 1 at our institution. Below is a plain-language breakdown of the two key topics we investigated.

🖥️

What is Virtualization?

Virtualization is the technology that lets one physical computer act as many. Using software called a hypervisor, a single server can run multiple isolated virtual machines (VMs), each with its own operating system and resources.

Think of it like converting a large house into separate apartments — the building (hardware) stays the same, but multiple independent families (VMs) can live in it simultaneously without interfering with each other. This is the foundation of modern cloud computing.

☁️

What is Cloud Computing?

Cloud computing is the delivery of computing services — servers, storage, databases, networking, software — over the internet ("the cloud") on a pay-as-you-go basis.

Instead of owning physical hardware, organisations rent resources from providers like AWS, Google Cloud, or Azure. This gives businesses flexibility, scalability, and cost savings — you only pay for what you use, and you can scale up or down in minutes.

🚀

Static Website Deployment

A static website is made up of fixed files — HTML, CSS, and JavaScript — that are delivered to the browser exactly as stored. There is no server-side processing or database involved.

Deploying a static site to the cloud means uploading these files to a cloud storage or hosting service (e.g., AWS S3, Netlify, or GitHub Pages) where they are served globally via a Content Delivery Network (CDN), making the site fast and highly available.

💡

Why This Matters

Cloud computing has fundamentally changed how software is built and delivered. Nearly every app you use today — streaming services, social media, online banking — runs on cloud infrastructure.

Understanding virtualization and cloud deployment gives developers and IT professionals the skills to build resilient, scalable, and cost-efficient systems that meet the demands of the modern digital economy.
